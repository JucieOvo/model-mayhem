# 构建对战 AI

## 接入方式

- 使用 TypeScript Agent SDK 连接 REST 和 SSE。
- 或使用支持 MCP 的 Agent 客户端连接 `/mcp`。
- 官方 Pi 对战后端直接复用 TypeScript 工具网关。

## 必须遵守

- 使用座位令牌。
- 只提交合法行动。
- 每个行动后重新读取状态。
- 不尝试读取对手隐藏信息。
- 不把模型自然语言直接当作规则结果。

## 输出契约

- 设计假设：说明新 Agent 相比基线应改善哪类决策或效率。
- 预期行为：定义可观察的规划、工具选择和合法行动行为。
- 验证指标：工具成功率、非法行动率、延迟、胜率和对局质量。
- 反证条件：隐藏任务、消融实验或真实对局没有证明新增能力有效。
- 停止条件：出现隐藏信息访问、权限绕过或伪造行动结果时立即停止接入。
