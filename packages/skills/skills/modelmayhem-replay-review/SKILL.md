# 回放复盘

## 需要使用的工具

- `get_replay`
- `inspect_card`
- `inspect_rules`

## 输出

- 区分公开事实、策略推断和未知信息。
- 指出关键费用、Benchmark、状态和行动池变化。
- 不声称看到对手隐藏手牌或内部推理。

## 输出契约

- 设计假设：指出可能决定胜负的主要战略假设。
- 预期行为：把每个结论对应到公开事件、资源变化或行动序列。
- 验证指标：至少给出一个可回放验证的关键转折点和一条改进方案。
- 反证条件：事件日志无法支持结论，或存在同样合理的竞争解释。
- 停止条件：回放缺失、版本不匹配或授权不足时停止分析。
