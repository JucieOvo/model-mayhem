# 编辑牌组

对战 Agent 不调用本 Skill。本 Skill 只用于玩家侧或独立牌组构建 Agent。

## 需要使用的工具

- `get_research_map`
- `inspect_card`
- `update_deck`

## 规则

- 蓝图牌堆必须包含 24 张组织、模型、技术或论文。
- 牌组必须声明 `china` 或 `west`，并与档案财团一致。
- 蓝图至少包含一张本财团公司卡。
- 对方财团公司不能进入牌组。
- 对方财团闭源模型不能进入牌组。
- 开放权重、开源、开放科学和全球资产可以跨财团使用。
- 同名牌最多两张。
- 至少包含 6 张模型和 5 张技术或论文。
- 招牌行动必须恰好配置 2 张，并且已经解锁。
- 未解锁卡牌不能进入牌组。

## 边界

- 不修改研究数据。
- 不绕过后端牌组校验。
- 不把 `global` 当作玩家财团。
- 对局开始后不能修改已锁定牌组。

## 输出契约

- 设计假设：说明这套牌组准备实现的财团路线、目标费用曲线和跨阵营开放资产。
- 预期行为：预测模型、组织、技术和招牌行动的配合方式。
- 验证指标：通过 `update_deck` 的真实校验，并满足收藏、数量、同名、财团公司和跨阵营边界。
- 反证条件：存在无法部署的模型、无效招牌行动或超过同名上限。
- 停止条件：未解锁卡、引用错误或结构校验失败时停止保存。
