# 社区数据分支静态查看器

## 目标与非目标

### 目标

为 `content/next` 和 `balance/next` 分别生成一个可独立打开的 `preview.html`。
查看器从分支真实数据目录读取 YAML，并在构建时嵌入同一条数据快照，不手写卡牌内容。

### 非目标

- 不替代正式游戏前端。
- 不修改卡牌数据和游戏规则。
- 不引入运行时服务、数据库或远端接口。
- 不把相同查看器复制到两个 stable 分支。

## 设计决定

在 `main` 增加一个通用生成器：

```text
scripts/build-community-preview.mjs
```

生成器读取指定分支工作树中的 `.modelmayhem/branch.yaml` 和 `content/`：

- `content` 模式渲染卡面展示、侃词、问题和缩略图。
- `balance` 模式渲染卡牌效果、平衡参数、预组、研究、时代和方针。
- 数据、缩略图、来源路径和统计信息全部嵌入生成的 HTML。
- 生成结果不访问网络，直接在浏览器打开即可使用。
- `--check` 模式可检查分支中的 HTML 是否与当前数据同步。
