# 沙盒作弊指南

沙盒模式明确允许玩家跳过成长、直接体验全部内容和快速测试胜利路线。

## 推荐流程

1. 在系统页启用 `MODELMAYHEM_SANDBOX` 和 `MODELMAYHEM_DEV_API`。
2. 打开“沙盒”页面。
3. 选择中国或西方财团。
4. 解锁全部卡牌和全部研究。
5. 增加足够的研究数据。
6. 创建沙盒对局。
7. 对局中使用悬浮作弊台增加算力、资本、影响力或直接胜利。

## 已有命令

- 设置沙盒财团。
- 解锁全部卡牌。
- 解锁全部研究节点。
- 增加研究数据。
- 推进当前时代。
- 修改对局算力、资本和影响力。
- 强制世界事件。
- 修改回合数。
- 查看对手完整状态。
- 直接胜利。
- 重置沙盒档案。

作弊只作用于沙盒档案。系统内容更新仍会检查官方内容文件，但不会因为玩家刷资源而停止。
