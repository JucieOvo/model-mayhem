# 《模型大战魔型》对战规则与胜利机制教程

## 一、先记住这局游戏在比什么

这局游戏不是把对手的模型打到零血，而是在双方共同经营 AI 产业组合的过程中，抢先把自己的影响力提高到 `18`。

一句话总结：

> 每回合把算力、资本、蓝图和行动牌转换成影响力，同时阻止对手完成同样的转换。

一局通常围绕三件事展开：

1. 建立场面和行动池，形成持续产出能力。
2. 通过行动牌、组织触发和 Benchmark 获得影响力。
3. 在接近胜利时阻止对手得分，或者抢先完成最后 1 至 2 点影响力。

## 二、胜利规则

### 1. 标准即时胜利

任意玩家的影响力达到 `18` 后，在每个原子效果结算后立即检查并结束对局。

例如：

```text
玩家影响力 = 17
打出开放权重发布
技术检定答对，获得 2 点影响力
影响力 = 19，按目标上限结算为 18
玩家立即获胜
```

不需要等到回合结束，也不需要等待对手回应。

### 2. 第 18 轮上限

如果第 `18` 轮结束时仍无人达到 `18` 影响力，只比较双方最终影响力：

- 影响力更高者获胜。
- 双方影响力相同则平局。

Benchmark 胜场、最高得分和模型数量会公开记录，但不参与第 18 轮的最终排序。

### 3. 同时达到目标

如果主动玩家的单一效果同时让双方达到 `18`，当前主动玩家优先获胜。

如果世界事件同时让双方达到 `18`，依次比较：

1. 当前影响力。
2. 本局 Benchmark 胜场数。
3. 本局最高单次 Benchmark 最终得分。
4. 场上有效模型数量。
5. 仍然相同则平局。

### 4. 投降

玩家可以主动投降。投降会立即结束对局，对方获胜。

## 三、三个核心资源

| 资源 | 性质 | 主要用途 |
|---|---|---|
| 算力 | 回合资源 | 部署模型、使用行动、发起 Benchmark |
| 资本 | 跨回合资源 | 部署组织、支付高成本行动 |
| 影响力 | 胜利进度 | 达到 18 点获胜，不作为货币消费 |

### 算力

```text
算力上限 = min(9, 2 + 当前玩家自己的回合序号)
```

每个自己的回合开始时，算力恢复到当前上限。未使用算力不会保留到下一回合。

### 资本

```text
资本收入 = 1 + 组织收入 + 临时修正
资本上限 = 12
```

资本可以跨回合保存，超过上限的部分丢失。

### 影响力

- 起始值为 `0`。
- 胜利目标为 `18`。
- 单轮最多净增长 `6` 点。
- 单次常规收益通常为 `1` 至 `2` 点。
- 单次夺取通常为 `1` 点。

影响力不是支付资源。你不能用影响力购买卡牌或支付费用。

## 四、开局流程

### 1. 双方蓝图起手

双方各获得 `5` 张蓝图手牌。

蓝图牌堆包含：

- 组织。
- 模型。
- 技术。
- 论文。

行动牌和世界事件不会进入蓝图牌堆。

### 2. 起手调度

开局先进行起手调度：

1. 选择任意数量不想要的蓝图牌。
2. 将选中的牌洗回蓝图牌堆。
3. 从牌堆补抽相同数量。
4. 双方确认后进入第 1 轮。

当前版本没有二次调度惩罚。

### 3. 行动手牌

| 座位 | 起始行动手牌 |
|---|---:|
| 先手方 | 0 |
| 后手方 | 1 |

后手方额外获得 `1` 点起始资本，作为行动顺序补偿。

## 五、每回合的固定流程

每个玩家回合严格按以下顺序执行：

```text
开始阶段
    -> 抽牌阶段
        -> 抽 1 张蓝图
        -> 抽 4 张行动
        -> 行动牌可以暂时超过上限
    -> 主要阶段
    -> 结束阶段
```

### 1. 开始阶段

- 自己的回合序号加一。
- 刷新算力。
- 获得资本收入。
- 触发回合开始效果。
- 检查状态合法性。

### 2. 抽牌阶段

每回合：

- 抽取 `1` 张蓝图，蓝图手牌可以暂时超过上限。
- 抽取 `4` 张行动牌。
- 行动牌可以先超过手牌上限。
- 如果行动手牌超过 `3` 张，可以继续使用手牌，也可以主动弃置。

行动手牌上限为 `3`。抽牌后可以继续使用手牌，结束回合前再处理超出部分：

```text
行动手牌 4 张 -> 弃置 1 张
行动手牌 5 张 -> 弃置 2 张
行动手牌 6 张 -> 弃置 3 张
行动手牌 7 张 -> 弃置 4 张
```

结束回合前：

- 如果通过使用行动已经把行动手牌降到 `3` 张以内，不需要额外弃置。
- 如果行动手牌仍然超过 `3` 张，必须先弃置到上限。
- 弃置时可以保留当前回合最可能形成影响力或继续抽牌的行动。

### 3. 主要阶段

每回合默认允许：

| 行动 | 上限 |
|---|---:|
| 部署组织 | 1 |
| 部署模型或技术 | 2 |
| 发起 Benchmark | 1 |
| 完成技术检定 | 1 |
| 使用普通行动 | 受手牌与资源限制 |

主要阶段可以调整守擂模型，也可以按任意顺序部署和使用行动。

### 4. 结束阶段

- 结算回合结束触发。
- 刷新或消耗状态。
- 确认蓝图与行动手牌不超过上限。
- 清理临时费用和临时能力修正。
- 重置本回合计数。
- 检查终局。

## 六、双牌库与手牌上限

### 蓝图

- 牌组规模：`24` 张。
- 同名牌最多：`2` 张。
- 至少包含：`6` 张模型。
- 至少包含：`5` 张技术或论文。
- 起始手牌：`5` 张。
- 每回合抽牌：`1` 张。
- 手牌上限：`5` 张。
- 分类保底：组织、模型、技术或论文三类中，任一类别连续 `3` 次未出现时，下一次优先抽取该类别。

蓝图是赛前构筑的长期资源。

蓝图手牌满 `5` 张后不会停止抽牌。新抽到的蓝图会暂时让手牌超过上限，玩家可以在主要阶段使用它，或者在结束回合前弃置回上限。

### 行动

行动牌来自动态行动池：

```text
行动池
    = 12 张通用行动
    + 每个有效组织据点提供的行动组
    + 2 张招牌行动
```

每回合抽 `4` 张。抽牌后可以继续使用，结束回合前把行动手牌降到上限 `3` 以内。

这意味着你部署什么组织，会真实改变未来可能抽到什么行动。行动池不是固定牌库。

## 七、四类卡牌

| 类型 | 代表内容 | 主要作用 |
|---|---|---|
| 组织 | 公司、平台、基础设施 | 长期据点，提供收入、容量和行动组 |
| 资产 | 模型、技术、论文 | 提供能力、费用修正、容量或 Benchmark 条件 |
| 行动 | 发布、开源、Benchmark、公关、攻击 | 抽到后执行一次性动作 |
| 世界事件 | 政策、硬件、市场、社区浪潮 | 双方共同承受的环境变化 |

梗、社区认知、传闻和现实调侃属于文本或标签，不单独构成卡牌大类。

## 八、牌桌区域

| 区域 | 规则 |
|---|---|
| 主实验室 | 固定存在，默认容量 2 |
| 组织槽位 | 3 个 |
| 组织据点容量 | 由组织卡决定 |
| 据点状态 | 默认最多 2 个 |
| 模型状态 | 每个模型最多 1 个 |
| 蓝图手牌 | 上限 5 |
| 行动手牌 | 上限 3 |
| 归档区 | 已结算或弃置的牌 |

组织和模型没有传统生命值。攻击不会直接扣血，而是修改资源、状态、得分、费用和影响力。

## 九、模型能力与 Benchmark

### 1. 四个能力维度

模型只有四个公开能力：

| 能力 | 含义 |
|---|---|
| 推理 | 数学、复杂推理和长链任务 |
| 编程 | 代码生成、调试和工程协作 |
| 代理 | 工具调用、规划和多步骤执行 |
| 多模态 | 图像、音频、视频和跨模态理解 |

模型能力不是宣传分数。游戏内数值只使用 `0` 至 `5`。

### 2. 模型得分

```text
模型得分
    = 基础能力
    + 技术修正
    + 组织修正
    + 世界事件修正
    + 状态修正
```

约束：

- 单项修正范围为 `-3` 至 `+3`。
- 最终得分范围为 `0` 至 `8`。
- 每个修正都必须公开来源。

### 3. Benchmark 发起

发起 Benchmark 需要：

- 拥有合法 Benchmark 行动。
- 拥有一个可参赛模型。
- 本回合尚未发起 Benchmark。
- 支付最终费用。

模型本轮参赛后不能再次参赛。

### 4. 对手模型选择

防守方可以提前公开指定一个守擂模型：

- 有合法守擂模型时优先使用守擂模型。
- 守擂模型失去资格时，自动使用当前最高分合格模型。
- 没有任何合格模型时，使用公开门槛。

### 5. Benchmark 类型

| 类型 | 胜利收益 | 附加效果 |
|---|---:|---|
| 标准 Benchmark | +1 影响力 | 败方模型承压 |
| 竞技 Benchmark | +2 影响力 | 败方模型承压 |
| 头条 Benchmark | +1 影响力 | 夺取对手 1 点影响力 |

平局时双方都不获得影响力，但双方参赛模型都获得承压。

### 6. 无对手门槛

```text
公开门槛
    = min(5, 1 + 向下取整((当前轮次 - 1) / 3))
```

| 轮次 | 门槛 |
|---:|---:|
| 1 至 3 | 1 |
| 4 至 6 | 2 |
| 7 至 9 | 3 |
| 10 至 12 | 4 |
| 13 及以后 | 5 |

## 十、影响力从哪里来

主要来源：

1. 行动牌直接获得影响力。
2. Benchmark 胜利。
3. 组织触发。
4. 世界事件。
5. 头条截胡等夺取效果。

同一个来源实例每轮最多贡献一次普通影响力。

单轮上限为 `6`。达到上限后，继续获得普通影响力的效果不会继续扩大优势，但其他非影响力效果仍按卡牌文本结算。

## 十一、攻击、状态与反制

游戏没有攻击力、防御力、命中和闪避。特效攻击直接修改公开状态。

| 攻击类型 | 结果 | 常见反制 |
|---|---|---|
| 算力压制 | 减少目标算力 | 先使用关键部署，保留算力 |
| 资本挤压 | 减少目标资本 | 提高储备，降低高成本依赖 |
| 评分压制 | 降低模型得分 | 更换守擂，争取环境修正 |
| 状态攻击 | 施加负面状态 | 热修、公关、证据、加固 |
| 费用污染 | 增加指定标签费用 | 延后部署，切换路线 |
| 影响力夺取 | 夺取 1 点影响力 | 控制差值，阻止完整结算 |

常见状态：

| 状态 | 作用 |
|---|---|
| 热度 | 下一次 Benchmark 得分 +1 |
| 争议 | 来源提供影响力时 -1 |
| 宕机 | 据点行动组失效，旗下模型不能参赛 |
| 过载 | 下一次从该据点部署模型费用 +1 |
| 监管 | 闭源或前沿标签效果失效 |
| 训练中 | 当前回合不能参赛，下一次对应能力 +1 |
| 加固 | 抵消下一次负面状态 |
| 势头 | 下一张行动算力费用 -1 |
| 承压 | 模型下一目标回合不能参赛 |

## 十二、世界事件与技术检定

### 世界事件

世界事件在第 `1、4、7、10、13、16` 轮开始触发。

规则：

- 同一时间只有一个世界事件。
- 事件同时影响双方。
- 事件主要修改标签、费用、能力或规则条件。
- 事件不能直接跳过玩家回合。

### 技术检定

部分高价值行动会触发四选一知识题。

```text
答对：执行强化效果
答错：仍执行基础效果
```

技术检定的作用是增强大招，不是阻止出牌。

界面上的 15 秒计时对应服务端真实截止时间。到时未作答时，服务端会按答错自动结算，
仍然执行行动的基础效果，并继续当前回合。

## 十三、阵营与构筑限制

玩家在账号建立时选择中国财团或西方财团。

阵营限制只作用于公司据点：

- 本财团公司可以部署。
- 对方财团公司不能部署。
- 全球平台、云服务和基础设施不受公司锁限制。
- 开放权重、开源、开放科学资产可以跨财团使用。
- 对方闭源模型默认需要明确访问权。

每套蓝图牌组必须：

- 正好 `24` 张蓝图。
- 至少一张本财团公司。
- 至少 `6` 张模型。
- 至少 `5` 张技术或论文。
- 同名牌最多 `2` 张。
- 携带 `2` 张招牌行动。

## 十四、如何规划一个回合

按以下顺序判断：

### 1. 先检查胜利线

- 自己能立即达到 18 吗？
- 对手下回合能达到 18 吗？

如果能立即赢，优先完成胜利线。

如果对手接近胜利，优先使用夺取、争议、承压或资源压制。

### 2. 完成弃置

- 保留能立即得分的行动。
- 保留能继续抽牌的行动。
- 保留能建立场面的组织或模型。
- 优先弃置当前无法支付、无法命中或收益过低的行动。

### 3. 计算资源

- 算力本回合用不完就消失。
- 资本可以保留，但上限为 12。
- 高成本模型不一定优于低费组合。

### 4. 选择行动顺序

常见顺序：

```text
先使用抽牌行动
    -> 找到更好的组合
再使用费用减免行动
    -> 降低后续部署成本
再部署组织和模型
    -> 建立长期得分能力
最后发起 Benchmark 或直接影响力行动
    -> 把场面转换成胜利进度
```

不要把顺序当固定公式，但每次行动前都要问：

> 这张牌是否让本回合或下一回合更接近 18 影响力？

## 十五、不同阶段的打法

### 0 至 8 影响力

重点：

- 建立组织。
- 部署至少一个可参赛模型。
- 扩大行动池。
- 保留抽牌和费用修正。

不要只堆模型，也不要只囤资本。

### 9 至 14 影响力

重点：

- 开始把场面转换成影响力。
- 使用 Benchmark。
- 保留守擂模型。
- 防止对手建立无法处理的持续收益。

### 15 至 17 影响力

重点：

- 每个行动都要服务于终局。
- 优先使用直接影响力。
- 优先夺取对手影响力。
- 不再为远期收益投入过多资源。

### 对手达到 15 以后

优先寻找：

- 影响力夺取。
- 争议。
- 承压。
- 算力和资本压制。
- 阻止对手模型参赛的状态。

## 十六、实战示例

以下是一局真实陪练对局的胜利过程，玩家最终以 `18:16` 获胜。

| 轮次 | 关键动作 | 局面 |
|---:|---|---|
| 1 | 社区分支、API 降价 | 建立早期影响力 |
| 2 | 继续社区分支，部署低成本模型 | 开始建立场面 |
| 3 | 开放权重发布，安装量化技术 | 模型获得后续得分基础 |
| 4 | 开放权重发布 | 缩小差距 |
| 5 | 社区分支、标准 Benchmark | 赢得一次 Benchmark |
| 6 | 社区分支 | 扩大到领先 |
| 7 | 社区分支 | 保持得分节奏 |
| 8 | 开放权重、技术报告、错误地挑战强模型 | 用弱模型 Benchmark 失败，暴露失误 |
| 9 | 弃置弱势牌，保留开放权重发布，技术检定答对 | 从 17 点直接到 18 点获胜 |

这局最重要的教训：

1. 抽到 4 张行动后可以先用手牌；结束回合前再处理超出的部分。
2. Benchmark 前必须确认自己的模型得分是否真的能赢。
3. 临近 18 时，不要再为了远期场面使用弱势 Benchmark。
4. 技术检定答对可以把关键行动从基础效果提升为增强效果。

## 十七、常见错误

### 错误 1：把影响力当成货币

影响力是胜利进度，不能用来支付费用。

### 错误 2：抽完 4 张就直接出牌

行动手牌超过 3 张时并不立刻中断出牌，但结束回合前必须通过使用或弃置降到上限。

### 错误 3：不看防守模型就挑战 Benchmark

对手守擂模型可能已经通过组织和技术获得 `+2` 或更多修正。

### 错误 4：只看即时收益，不建立行动池

组织会改变未来行动牌分布。长期对局中，行动池质量非常重要。

### 错误 5：在 17 影响力时继续铺场面

如果存在直接获胜线，优先赢，不再为下一轮投资。

### 错误 6：算力不用完

算力不能跨回合保存。能形成有效行动的算力应在本回合使用。

### 错误 7：资本溢出

资本上限为 `12`。溢出后的收入会丢失。

## 十八、速查卡

```text
胜利：影响力达到 18
轮次上限：18
单轮影响力增长上限：6

蓝图：开局 5，每回合抽 1，结束回合前降到上限 5
行动：每回合抽 4，结束回合前降到上限 3

算力：回合恢复，不保留
资本：跨回合保留，上限 12
影响力：只用于胜利，不用于支付

组织部署：每回合 1
资产部署：每回合 2
Benchmark：每回合 1
技术检定：每回合 1

世界事件轮次：1、4、7、10、13、16
```

## 十九、给 Agent 接入者的最短规则

1. 只提交服务端 `availableActions` 中的完整语义行动。
2. 不自行生成 `actionId` 或 `commandId`。
3. 行动手牌超上限时仍可正常使用手牌，也可以提交 `discard_action`。
4. 蓝图手牌超上限时可使用或提交 `discard_blueprint`，且每类蓝图有分类保底。
5. 结束回合前必须把蓝图和行动手牌分别降到上限以内。
6. 技术检定答错仍执行基础效果。
7. Benchmark 前必须检查双方公开模型得分和资格。
8. 不读取对手隐藏手牌或技术检定答案。
9. 工具失败时报告真实错误，不伪造成功。
